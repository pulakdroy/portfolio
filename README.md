# pulakdroy/portfolio

Welcome to the repository for **pulakdroy's personal portfolio** website! This project showcases professional experience, projects, skills, and contact details in a responsive, modern web format.[1]

## Demo

Check out the live portfolio at:  
[https://pulakdroy.vercel.app](https://pulakdroy.vercel.app)[1]

## Features

- Clean, minimal design focused on accessibility and user experience[1]
- Fully responsive across desktop and mobile devices[1]
- Sectioned layout: About, Skills, Projects, Contact[1]
- Built with HTML and CSS for easy customization[1]


## Getting Started

### Prerequisites

- Modern web browser
- Node.js and npm (if you want to run a development server)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pulakdroy/portfolio.git
   ```
2. Open the project folder:
   ```bash
   cd portfolio
   ```

3. If you want to use a static web server (optional):
   ```bash
   # For example, using VS Code Live Server extension or:
   npx serve .
   ```

4. Open `index.html` in your browser to explore the site locally.

## Customization

- Update the `index.html` and other HTML files to personalize content
- Modify styles in `style.css` or relevant CSS files for color, layout, and branding
- Add new sections or projects as your portfolio grows

## Deployment

This portfolio is easily hosted on services like Vercel, Netlify, or GitHub Pages for free.  
To deploy using Vercel:
- Push code changes to GitHub
- Connect your repository at [https://vercel.com/](https://vercel.com/)
